# Lessons

- Before recommending "keep the current setup" or "no extra harness needed", confirm the user's actual goal: here it was to tear down and consolidate the existing harness and to run one identical harness across multiple environments, not to add to it.
- When a Korean instruction uses "빼고" (it can mean "except" or "remove"), restate which items will be removed before acting.
- Before attributing a decision to the user, check the session logs and separate a direct request from approval of an agent proposal; cite the message and its date.
