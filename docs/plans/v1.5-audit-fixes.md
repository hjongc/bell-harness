## Interfaces
§1 Moved repository.
- `harness.previous_roots(home)`: read every `manifest.jsonl` under `~/.bell-harness/backups/*/` (restored backups included); for each JSON line with `"action": "git-config"` and a string `value` ending in `/git/hooks`, yield the path two levels above that value. Ignore unreadable files and malformed lines. Exclude the current root.
- `bin/setup` preflight: a global `core.hooksPath` that differs from the current hooks path is accepted when its parent's parent is in `previous_roots`; the plan then contains the usual `git-config` action. Any other foreign value still exits 2.
- A link whose target lies inside a previous root counts as managed everywhere `is_managed` is used by setup (relink without treating it as a foreign entry to report; it is still moved into the backup before relinking, as today), and a stale link into a previous root is removed like any stale harness link.
- Test: install in a temporary home, rename the harness directory, run `bin/setup` from the new location: exit 0, links point to the new location, `core.hooksPath` is the new path, and a second run prints `setup: nothing to do`.

§2 Eval runner.
- Codex: a harness skill counts as loaded only when a command contains `.agents/skills/<name>/SKILL.md`.
- Claude: a `Skill` call whose `skill` contains `:` is ignored; otherwise the name is used as is.
- A case may set an integer `max_turns` (Claude only; default 8).
- `--repeat N` (default 1) runs each host and case N times. One line per host and case: with N=1 the line is unchanged; with N>1 it reads `PASS|FAIL <host> <case>: <k>/<N> passed ...` followed by the detail of the first failing attempt, and the run passes only when k equals N. The final line counts host-case pairs as before. `--json` records every attempt.
- Tests with stubs: a Codex read of `<elsewhere>/skills/spec/SKILL.md` is not a load; a Claude call to `other:spec` is not a load; `max_turns` reaches the command line; `--repeat 2` with one failing attempt reports `1/2 passed` and FAIL.

§3 Legacy decision lines.
- `decisions.legacy(root)`: for each `docs/plans/*.md`, count lines matching `^- D[0-9]+\b` that are outside a `## Decisions` section and outside code fences; return `(relative path, count)` for files with a count above zero.
- `bin/doctor --project`: one line per such file, `WARN legacy decisions: <path> has <n> decision-like line(s) outside "## Decisions" (run the map skill to migrate)`.
- This repository must produce none.
