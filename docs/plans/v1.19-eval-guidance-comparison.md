## Prerequisites

v1.16 must have produced the proposed skill sentence with its evidence. Prepare synthetic fixtures and judge checks offline. Live execution requires a separate approval for the selected hosts and a bounded budget. The plan uses at most eight sessions and avoids retries within the measured comparison.

## Scope and protocol

- Prepare two small Python CLI tasks in history-free fixtures. In the packaging task, a preview must read a template from the installed artifact even when the source tree has a different copy. In the retry task, a local event receipt is persisted once per event ID across separate invocations.
- Freeze expected results independently before execution. For preview, test an installed launch outside the source tree, a non-ASCII title and a missing installed template. For receipts, test a first event, its retry on a separate invocation, a different event and malformed input that leaves state unchanged. Provide the behavioral contract to both groups and keep exact judge inputs outside both fixture trees.
- For each selected host and task, use separate temporary worktrees and the same initial files, prompt, host version, permissions and budget. Explicitly apply the eval skill in both groups and vary only the v1.16 sentence. Alternate which group goes first. Keep project writes limited to the temporary worktree and use synthetic inputs. Use the existing read-only eval runner for its existing cases.
- Review condition-blind patches and reports against normal CLI behavior, scope and allowed effects before revealing labels. Record verification evidence, skill selection and elapsed time separately, and keep per-task and per-host results visible. The offline preparation can exercise the judge with a known bad artifact and a valid reference.
- A candidate that eliminates at least one variant failure with no new required behavior failure or unauthorized effect is worth a larger comparison. A tie or incomplete pair supports no change in guidance. Claims are limited to the observed tasks and sessions.
