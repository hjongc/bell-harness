# v1.8-check-speed: run isolated check suites in parallel

Status: implemented

## Context

The serial `scripts/check` run passed 93 tests in 121.430 seconds. The suite uses independent temporary homes, checkouts and Git configurations. Run its discovered suites in a bounded process pool and keep the existing serial runner for comparison.

## Decisions

- D1: Run discovered unittest suites in isolated processes with at most four workers by default -- why: the fixtures spend most of their time in independent Git and CLI subprocesses, while process isolation preserves per-test globals and mocks -- by: observed -- paths: scripts/check

## Scope

- `scripts/check`: accept `--jobs N`, use the same unittest discovery for both modes, and report the combined result and home guard.
- `README.md`, this spec and `docs/plans/roadmap.md`: document how to run either mode and record the timing comparison.
- No test changes, dependencies, CI changes, live setup, model calls, or changes to what the real-home guard compares.

## Acceptance tests

1. `scripts/check` and `scripts/check --jobs 1` run the same 93 tests and print `GUARD: real home unchanged`.
2. An isolated failing test produces a nonzero exit and the home guard still runs. A watched test-home change alone also fails the check. Suites that cannot be serialized run serially before any worker starts.
3. Measure both modes on the same working tree and report their wall times. Keep the parallel default only if it improves the observed runtime.

## Done criteria

The acceptance checks pass. Only the scoped files change for this spec.

## Verification

| Command | Wall time | Test runner time | Result |
|---|---:|---:|---|
| `scripts/check` | 63.191 s | 62.714 s | 93 passed, home guard clean |
| `scripts/check --jobs 1` | 119.659 s | 119.300 s | 93 passed, home guard clean |

Both modes ran the same 93 test names on the same working tree. The four-worker run reduced wall time by 47.2 percent in this comparison. With isolated fixtures, a test assertion and a watched home change each returned 1. A suite holding a local function ran both tests serially and returned 0.
