# Roadmap

Specs in the order they run. An unchecked item starts without asking when its spec says `Status: approved`; anything else waits for the user. The actions in the global "When to stop and ask" list need approval either way.

- [x] v1-hooks-config: git hooks, host config and global instructions
- [x] v1-memory: decision records and recall rules
- [x] v1-setup-doctor: install, restore and check
- [x] v1-skills: six shared skills, sources and readme
- [x] v1-evals: live evals for skill routing and project memory
- [x] v1.1-flow-init: init skill, roadmap flow, one instruction file per project
- [x] v1.2-field-fixes: fixes from the first real init run, Korean routing evals, CI
- [x] v1.3-away: away skill and a ceiling on global rules

- [x] v1.5-audit-fixes: decisions and fixes from the audit backlog
- [x] v1.6-regression-loops: six diagnosis, fix and verification rounds
- [x] v1.7-path-boundaries: five filesystem and verifier audit rounds

- [x] v1.9-project-doctor: read-only project diagnostics and batched commit validation
- [x] v1.10-backup-inventory: list backups and verify backup-record paths
