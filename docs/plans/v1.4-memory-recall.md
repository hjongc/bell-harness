# v1.4-memory-recall: keep project guidance aligned with decisions

Status: implemented (offline checks and live evals)

## Context
Both hosts already use Git decision records. A Sources of truth row can still send a fresh session to an obsolete decision even when every cited file exists. A Korean request and a tentative observation also exercise recall behaviors beyond the four existing cases.

## Decisions
- D1: Keep durable reasoning with its project and recheck it in the current checkout -- why: the same decision must travel between tools and machines without relying on session history -- by: user
- D2: A decision record may be hard-wrapped onto indented continuation lines -- why: the first real project wraps prose at 80 columns, and its valid records were reported as missing fields -- by: observed -- paths: lib/decisions.py tests/test_decisions.py

## Scope / Non-goals
Use the existing decision checker, init refresh and live eval runner. Keep the no-index and no-recall-hook gate from v1-memory#D2. Personal preferences stay outside this public repository. Existing plans remain the home for in-progress work.

## Changes by file
- lib/decisions.py and tests/test_decisions.py: check decision ids in the constraints column of the root Sources of truth table, including multi-step replacement.
- skills/init/SKILL.md, skills/spec/SKILL.md, README.md and SOURCES.md: describe focused repair and how to resume work from the current checkout.
- evals/fixtures/memory/docs/plans/hooks.md, evals/cases/memory-reason-ko.json, evals/cases/memory-observed.json and tests/test_evals.py: cover bilingual evidence retrieval and distinguish approval from observation.
- docs/plans/roadmap.md and this spec: track the work.

## Interfaces
Use the existing decisions.check and doctor project diagnostics. Report the source row and the missing id or the active replacement ids. A row may mention a historical id together with its current successor. Inspect only the constraints column in the named section.

## Acceptance tests
1. An unknown citation and an obsolete citation are reported without any file move. Valid current references and historical references accompanied by their successor pass. Off-table text is ignored. A cycle must not hang the check.
2. Both new prompts ask for a compact answer with its decision id. Require the system interpreter rationale for the Korean prompt and the observed status plus the optional action for the second. Stub tests exercise correct and incorrect answers.
3. Existing setup, normal refresh, and live-run approval boundaries remain in force. Paid runs require separate approval.

## Done criteria
scripts/check, python3 lib/decisions.py, python3 lib/privacy.py and git diff --check exit zero; changes are limited to the listed files. Report paid eval results separately when approved.
